# 道德经

一章一页，读其文，观其象，记其所悟。

这是我个人学习《道德经》的笔记。八十一章各有一页：先呈现原文，再配一幅由 AI 依本章意会所作的图、一段 AI 解读；读的过程中我与 AI 继续讨论，最后把自己的心得提炼出来放上去。内容会随学习进度逐章补齐。

原文采用通行本（王弼注本）。

## 阅读

- 方向键 ← → 或在手机上左右滑动翻章。
- 右上角“卷目”可跳到任一章；有红点的章节已有札记。
- 原文可切换横排、竖排。
- 页面会记住上次读到的章节。

## 本地预览

纯静态页面，无需构建。直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 内容结构

全部内容在 `chapters.js`，每章一个对象：

| 字段 | 含义 |
| --- | --- |
| `text` | 原文 |
| `image` / `imageNote` | AI 配图（21:9）与创作思路 |
| `aiInterpretation` | AI 解读 |
| `aiDialogue` | 与 AI 对谈的精炼记录 |
| `personalUnderstanding` | 我的心得 |
| `sharedReading` | 与人共读的交流 |
| `quote` | 一句收束之语 |

配图放在 `assets/chapter-NN.webp`。

## AI 协作

本项目的内容由我与 AI 共同完成。AI 需要遵守的规则（原文不可改、心得不可代写、解读准则、配图规范等）统一写在 [`AGENTS.md`](./AGENTS.md)。
